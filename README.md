# AK Biryani House — Real Online Ordering Website

This project follows the black + gold mobile flow you supplied:
Welcome → Phone OTP → Verify → Menu → Cart → Delivery → Payment → Order Confirmation → Owner Order Dashboard.

## Important: real OTP
The site is built to use Supabase Phone Auth. Real SMS OTP is NOT generated by this HTML file itself. You must connect a Supabase project and an SMS provider (such as Twilio/MessageBird/Vonage) in Supabase Auth.

### 1. Create Supabase
Create a Supabase project and open SQL Editor.
Run **schema.sql**.

### 2. Enable Phone Auth
In Supabase: Authentication → Providers → Phone.
Enable phone sign-in and configure a supported SMS provider.

### 3. Add website keys
Open `supabase-config.js` and replace:
- PASTE_YOUR_SUPABASE_PROJECT_URL
- PASTE_YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY

Use the publishable/anon key only. Never put a service-role/secret key in browser JavaScript.

### 4. Create owner account
For the owner dashboard, create an email/password account in Supabase Authentication → Users (or your own secure signup flow).
Then copy that user's UUID and run:
```sql
update public.profiles set role='admin' where id='OWNER-USER-UUID';
```

Open `admin.html` to manage orders and change status.

## 5. Host it
Netlify is the easiest option:
1. Put all files in one folder.
2. Go to Netlify.
3. Add new project → Deploy manually.
4. Drag the project folder into the deploy area.
5. Netlify gives you a live URL.
6. Add your custom domain later if you own one.

## 6. Production checklist
- Add your real restaurant phone/address.
- Configure SMS provider and Indian SMS/TRA​I/DLT requirements as applicable.
- Add a real payment gateway only after you have a merchant account and server-side payment verification.
- Keep the Supabase service-role/secret key off the frontend.
- Configure CAPTCHA/rate limits for OTP abuse.
- Test OTP, order insertion and admin RLS before advertising the URL.

## Files
- `index.html` — customer website
- `style.css` — responsive black/gold design
- `app.js` — menu, cart, OTP and order flow
- `supabase-config.js` — your public Supabase project URL/key
- `schema.sql` — database, RLS and admin role
- `admin.html` — restaurant owner dashboard
- `admin.css` — dashboard styles

The menu, cart and UI work locally. Real OTP and real cloud orders begin after Supabase is configured.
