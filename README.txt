# AK Biryani House Website

A responsive restaurant ordering website inspired by the requested AK Biryani House interface.

## Files
- index.html — complete website
- style.css — dark/gold restaurant UI
- script.js — login/OTP, menu, cart, delivery, payment, order confirmation and bill
- ak-biryani-ui-reference.png — UI reference image

## How to run
1. Download/extract the ZIP.
2. Open `index.html` in Chrome.
3. Enter any 10-digit phone number.
4. For the demo OTP, enter any 4 digits.
5. Explore menu → add items → cart → delivery → payment → bill.

Food images are loaded from Unsplash, so an internet connection is recommended.
